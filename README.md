# HTTPeep Homebrew Tap

Official Homebrew tap for [HTTPeep](https://httpeep.com/), an HTTP and HTTPS proxy debugging tool.

## Install

```sh
brew install --cask httpeep/httpeep/httpeep
```

You can also tap first:

```sh
brew tap httpeep/httpeep
brew install --cask httpeep
```

## Upgrade

```sh
brew update
brew upgrade --cask httpeep
```

## Uninstall

```sh
brew uninstall --cask httpeep
```
